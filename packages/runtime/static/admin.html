        Admin access & sign-in

        Password-less login with Cloudflare Access is built in: protect /admin.html with an Access application and set the Worker var CF_ACCESS_TEAM (optionally CF_ACCESS_AUD) — the login screen then shows "Sign in with Cloudflare" and you never type a password. The hosted installer offers this in step 3.

        Lost the admin password? With Cloudflare Access enabled, just sign in with Cloudflare. Otherwise rotate it: npx wrangler secret put ADMIN_SECRET (you choose the new value) — or reinstall fresh. Re-running the installer preserves your existing secrets (including the current password) by design.
