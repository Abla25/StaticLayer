No account, no email — ready to connect your Cloudflare account.

Connect Cloudflare

Both methods need a one-time permission from you — after that everything is automatic. Pick whichever you prefer.

Which one?
Fastest nowInstalling once → paste an API token (fewest steps, no registration).
Best repeatInstalling often → OAuth (one click per install, after a one-time setup).
Option A — Connect with Cloudflareone click after setup

Authorize in your browser with the minimal scopes (Workers deploy, D1, account read). The token is revoked right after the deploy.

How to enable this option (one-time setup)
  1. In the Cloudflare dashboard go to Manage Account → OAuth clients → Create client.
  2. Fill in: response type code, grant authorization_code, token auth client_secret_post, redirect http://localhost:8788/oauth/callback.
  3. Scopes: workers-platform.write, d1.write, account.read.
  4. Put CLIENT_ID and CLIENT_SECRET in apps/installer/.env.local and restart the installer.
  5. From now on every install is one click: Connect → Approve → done.
Option B — Paste an API tokenfastest for one-time

Create a token with 3 permissions and paste it here. Open API tokens ↗

  1. Open API tokens ↗ → Create Token → Custom token.

  3. Workers Scripts → Edit — deploys the Worker.
  4. Cloudflare D1 → Edit — creates and manages the database.
  5. Account Settings → Read — lists your accounts.
  6. Create → copy the token → paste it above. It is validated instantly, kept only in memory, and cleared after the deploy.
Comment data never touches our servers. With OAuth the token is revoked after the deploy; with a pasted token it lives only in memory here and is cleared after the deploy.
