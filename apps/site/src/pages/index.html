03 — Engagement

Three ways to engage. One privacy model.

Comments, reactions and (coming) votes share the same architecture: anonymous, PoW-protected, running in your Cloudflare account.

Comments

Conversations, moderated

Plain-text replies in per-page threads. Every comment goes through a moderation queue you approve from the admin console.

  • Text only · nickname ≤ 50 · body ≤ 3000
  • Moderation: approve / unapprove / delete
  • Per-page threads, one admin queue
Documentation →
Reactions

One-tap, anonymous

Emoji counts with a real Proof-of-Work per click. Difficulty rises as a page gets busier; no moderation, no identity.

  • Cost-based integrity (not identity)
  • Escalating difficulty + rate limits
  • Fully themeable, choose the emoji set
Guide →
Votes

Up / down — coming

Up/down ratings on the same engine (PoW + anti-replay + rate limits). Planned, not yet shipped.

  • Same integrity model as reactions
  • Optional identity mode for strict 1-vote
  • On the roadmap

10 — FAQ

Quick answers

Does StaticLayer host my comments?

No. The runtime is deployed in your Cloudflare environment. There is no centralized comment database.

Do visitors need an account or email?

No. Visitors just write a nickname and a plain-text comment.

Does the widget track visitors?

No. The public widget does not use tracking cookies, local storage, fingerprinting or analytics.

Is it automatically GDPR compliant?

No. StaticLayer is designed to minimize data processing, but site owners remain responsible for their own legal compliance.
